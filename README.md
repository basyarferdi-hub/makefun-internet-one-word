# The Internet in One Word — make.fun entry

A tiny, deterministic Python program that writes one word to `entry.txt`.

- Bounty: https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b
- Rule: one English word, 1-30 characters, letters only. This entry: "Everything" (10 letters).
- Run: `python3 main.py` — writes `/output/entry.txt` in the grader,
  or pass a local path for testing: `python3 main.py out/entry.txt`
- No network, no dependencies, Python 3.13 compatible. MIT licensed.
